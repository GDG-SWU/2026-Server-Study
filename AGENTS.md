# Project preferences

- Use Java 17 unless the user explicitly requests another Java version.
- The user reviews and runs Java projects in IntelliJ IDEA. Keep projects importable as Gradle projects and provide IntelliJ-oriented instructions.
- Preserve existing learning code; create separate practice projects when requested.
- Do not push to any remote unless the user explicitly requests a push. A request to create a branch or commit is not permission to push.
